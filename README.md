## Quick Start

```python
from quantum_core import QuantumCircuit

# Create a 2-qubit quantum circuit
qc = QuantumCircuit(2)

# Apply quantum gates
qc.h(0)  # Hadamard gate on qubit 0
qc.cx(0, 1)  # CNOT with control=0, target=1

# Measure the qubits
result = qc.measure()
print("Measurement result:", result)
```
